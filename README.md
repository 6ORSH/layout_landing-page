# Landing Page

A responsive landing page built as a frontend layout exercise.
The project is intended to demonstrate a clean, modern landing design using HTML, SCSS, and JavaScript (for small interactive behaviors), and be deployable via GitHub Pages.

## Technologies Used
- HTML5
- SCSS (Sass)
- JavaScript (vanilla)
- Node.js + npm (build tooling)
- GitHub Pages (for deployment)

## Launch / Run Locally
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start dev server:
   ```bash
   npm start
   ```
3. Build for production:
   ```bash
   npm run build
   ```
